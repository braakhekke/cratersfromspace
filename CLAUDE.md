# CLAUDE.md: Craters from Space

Public dashboard of ten of the world's most active volcanoes in Sentinel-2 imagery: one clear scene per eruption event since 2016, with Smithsonian GVP facts, a compare slider, a timelapse, a single-image export and an animation (video) export. Sister project of Swiss Glacier Tongues from Space (`../tonguesfromspace`, same architecture). Site: https://braakhekke.github.io/cratersfromspace/. Non-commercial (see Licences).

## Files

| File | Role |
|---|---|
| `index.html` | The whole site: one file, no build step. Leaflet 1.9.4 from cdnjs. Links can carry a hash: `v` volcano, `m` mode, `a`/`b`/`from`/`to`/`one` event ids, `s` colour style (`natural`, `swir`, `infra`). |
| `volcanoes.js` | Generated by `scripts/build_volcanoes.py` (GitHub Action, monthly). Never edit by hand. |
| `fonts/` | Schibsted Grotesk variable woff2 (copied from the glacier site). |
| `config.js` | Written by the deploy workflow: `window.CFS_CONFIG = { relay: <CDSE_RELAY_URL> }`. Not in the repo (a local stub is gitignored). |
| `scripts/build_volcanoes.py` | The curated list of ten volcanoes (`VOLCANOES`: id, GVP number, name, half footprint in km) + GVP web service (facts, eruption records) → events → `volcanoes.js`. Standard library only. |
| `scripts/serve.py` | Local server + Copernicus relay. Credentials: env `CDSE_CLIENT_ID` / `CDSE_CLIENT_SECRET`, or `scripts/.cdse-credentials` (gitignored), or a prompt. |
| `worker/worker.js` | Cloudflare Worker = public Copernicus relay with request validation and KV cache. Its own Worker and KV, separate from the glacier site. |
| `.github/workflows/deploy.yml` | On push to main, monthly cron, or manual: build data → commit `volcanoes.js` → write `config.js` → deploy Pages. |

## Where things live in `index.html`

Script sections are marked with `/* ===== n. Title ===== */` comments: 1 static data, 2 imagery (CDSE settings and `version`, scene scoring, colour process, relay calls, caches, `loadImage`), 3 state and URL hash, 4 map (panes, compare clip, timelapse), 5 scene search (`checkEvents`), 6 rendering (pickers, modes, volcano list, story tabs Facts / Eruptions / About), 7 download (frame on the map, drawing, WebCodecs H.264 encoding, `muxMp4` = own MP4 packer, copied from the glacier site), 8 boot.

## Data flow

```
browser ── /cdse/statistics, /cdse/process ──> relay ──> Copernicus Data Space (Sentinel Hub APIs)
           relay = worker/worker.js on the public site (config.js), scripts/serve.py locally
build_volcanoes.py ── GVP WFS (webservices.volcano.si.edu) ──> volcanoes.js
```

- **Events:** each GVP eruption record that overlaps the Sentinel-2 era (from 2016-01-01) is one event; records longer than 150 days are split per calendar year. The scene search period (`find`) is at least 30 days from the start. Labels like "2023", "Jan-Jun 2022". Only GVP data: never add events from memory.
- **Scene choice:** Statistical API, Sentinel-2 L2A, SCL cloud classes (3, 8, 9, 10; snow is ignored), per day and per orbit (a scene is date + orbit; the image is made from that orbit only). Earliest scene with ≤ 5 % cloud, else least cloudy ≤ 30 % ("some clouds", dashed chip). Ash and steam plumes count as cloud.
- **Images:** Process API, Sentinel-2 **L1C** of the chosen day, Copernicus Browser true-colour process. Band combinations: natural B04-B03-B02, `swir` B12-B8A-B04 (hot ground glows), `infra` B08-B04-B03. Footprint: a square of 2 × `half` km around the GVP summit, 10 m pixels (max 2500 px).
- **Worker validation:** the request must lie within 30 km of one of the ten centres (`CENTRES` in `worker/worker.js`, keep in step with `VOLCANOES`); dates from 2016-01-01; statistics periods up to 400 days.
- **Caches:** browser IndexedDB `cfs-cache`; Worker KV `CACHE` (180 days; running periods 1 day). Free plan: 1,000 KV writes a day.
- **Other sources, without the relay:** EOX Sentinel-2 cloudless tiles (background), OpenStreetMap, EOX place labels.

## Rules

- **Raise `CDSE.version`** (section 2) whenever scene scoring or image rendering changes.
- **After any change to `worker/worker.js`,** tell the user to paste it into the Cloudflare dashboard (Worker → Edit code → Deploy). New request types must also be allowed in `checkProcess` / `checkStatistics`.
- **Adding a volcano:** add it to `VOLCANOES` in `scripts/build_volcanoes.py` and its centre to `CENTRES` in the Worker.
- **All figures and texts:** only documented facts, with a source (GVP). Never invent data, dates, field names or sources.
- **Licences:** GVP (Smithsonian Terms of Use, non-commercial use; credit "Global Volcanism Program, Smithsonian Institution"), EOX background CC BY-NC-SA 4.0, Copernicus data allows commercial use, so the site is non-commercial. Keep the credits line and the Sources list complete when adding data. Code MIT (`LICENSE`), own texts CC BY 4.0.
- **No CSS or SVG filters on page elements for image effects:** Safari on iPhone ignores them. Process pixels in a canvas.
- **Edit whole CSS rules or functions;** partial find/replace has broken selectors before.
- **Async searches (`checkEvents`) use a generation counter;** keep stale results from overwriting newer ones.
- **The user edits files himself between sessions.** Always work from the current file.

## Style

Calm and compact, little text, UI text in English. Accent `--accent: #D9481C` (lava orange) for headers; white cards with grey tiles. Left panel: 1 Choose a volcano, 2 Visualise, 3 Download and share. On phones: map first, then that panel, then the story; two fingers move the map.

## Testing a change

1. **Syntax / page:** `python3 -m http.server`, open in a browser or headless Chrome and check the console.
2. **Locally with real data:** `python3 scripts/serve.py`, open http://localhost:8000. Check the status box ("Scenes found…"), compare, timelapse, the three colour modes, the Facts / Eruptions / About tabs, and a phone-size window.
3. **Animation:** create a short 9:16 video; `ffprobe` should show H.264, 1080×1920, 30 fps.
4. **Worker changes:** test with `serve.py` first, then deploy and open `<worker-url>/cdse/ping` → `{"relay":true,"managed":true}`.
5. **Data:** `python3 scripts/build_volcanoes.py` prints the ten volcanoes with events.

## Deployment checklist for the user

- **Site:** commit and push; the GitHub Action builds and deploys. Enable Pages once: Settings → Pages → Source: GitHub Actions.
- **Worker:** create a new Worker (e.g. `cratersfromspace-relay`), paste `worker/worker.js`, add secrets `CDSE_CLIENT_ID` / `CDSE_CLIENT_SECRET`, text `ALLOWED_ORIGINS`, and a KV namespace bound as `CACHE`.
- **Repository variable `CDSE_RELAY_URL`** = Worker address; changing it requires a new workflow run.
